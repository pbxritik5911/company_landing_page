## 📌 Project Description

This project is a simple Company Landing Page developed as part of the Web Programming Lab assignment.  
The objective of this experiment is to understand the fundamentals of front-end web development using HTML and CSS.

The landing page represents a fictitious company and demonstrates basic website sections commonly used in real-world business websites.

---

## 🛠 Technologies Used

- HTML5  
- CSS3  
- Visual Studio Code

## ✨ Features

- Header / Hero section with company name and tagline  
- About section introducing the company  
- Services section with three service cards  
- Testimonials section with customer feedback  
- Contact section with email, phone, and simple contact form (UI only)  
- Clean layout using CSS box model (margin, padding, borders)  
- Semantic HTML tags such as header, section, and footer
